# Prompting AI for Legal Research

An interactive, self-paced tutorial on using AI tools within a sound legal research process: framing the question, choosing the right source, retrieving authority, evaluating answers, and verifying the law.

**Live site:** https://eli-uclalaw.github.io/Legal-Research-AI-Tutorial/

## What's inside

- Lessons on the six-stage research loop, task-first prompting, and prompting frameworks
- Best practices by tool type (general AI assistants, legal research databases, drafting agents)
- Exercises with instant feedback and writing exercises with automated pattern feedback
- A "My work" panel for copying everything a student wrote

Nothing a student types is saved or sent anywhere; reloading the page clears it. Case names in simulated AI responses are fictional and exist only for training.

## Running it

The whole tutorial is a single file, `index.html`, with no build step or dependencies. Open it in any browser, or host it with GitHub Pages.
